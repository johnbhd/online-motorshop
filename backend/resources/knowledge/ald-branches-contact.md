# ALD Motorshop Branch and Contact Guidance

Current public Branch names, addresses, contact numbers, pickup availability,
and active visibility come from the live Laravel Branch records. This document
contains only the retrieval boundary; it is not a list of branches and must
never be used as a fallback for a missing or failed database result.

The current Branch schema does not store business hours. When a customer asks
about hours, advise them to confirm with ALD Staff or the relevant Branch
before visiting rather than inventing a schedule.

Only active public Branch records may be recommended. Inactive Branches,
internal IDs, Staff assignments, private Staff contact information, internal
notes, metrics, and credentials are never included in Assistant context.

Pickup availability comes from the current Branch record. A pickup-enabled
Branch still requires staff confirmation during the Order Request process.
